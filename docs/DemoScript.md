# Demo Script - 5 to 7 Minutes

1. **Problem and observation** - One musical approach does not produce the same experience for every autistic person.
2. **Project boundary** - This is a synthetic educational simulator, not a clinical predictor.
3. **Persona design** - Show multidimensional sensory, communication, routine, and support fields.
4. **Music trial** - Configure genre, BPM, volume, instrument, tonality, duration, lyrics, and scenario.
5. **Two engines** - Explain deterministic reproducibility and optional AI structured outputs.
6. **Provenance** - Show trial ID, engine, model, prompt version, seed, timestamp, and disclaimer.
7. **Dashboard** - Show heatmap and anxiety-engagement comparison.
8. **Research result** - Present patterns only as synthetic model behavior.
9. **Limitations** - Five fictional profiles do not represent autistic people; no clinical conclusion is possible.
10. **Future work** - Participatory design, expert review, stronger evaluation, and ethics review before any real-person data.

## Offline fallback

Use deterministic mode with pre-seeded personas. Never depend on a live API during the final presentation.
