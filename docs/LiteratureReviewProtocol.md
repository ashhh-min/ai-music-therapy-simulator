# Literature Review Protocol

## Review questions

1. What outcomes have music-therapy studies measured for autistic people?
2. How certain is the evidence for each outcome?
3. What sensory and individual-difference factors are relevant to auditory experiences?
4. What limitations should an AI simulation disclose?

## Source hierarchy

1. Systematic reviews and meta-analyses.
2. Peer-reviewed controlled studies.
3. Authoritative health-agency overviews.
4. Professional organizations and self-advocacy perspectives.
5. Books and explanatory resources used only for context.

## Extraction table

For each source, record citation, population, intervention, comparison, outcome, study design, sample size, result direction, evidence certainty, limitations, and the exact claim the project may support.

The populated extraction table is `docs/evidence_table.csv` (eight sources logged at S02, each with limitations). The claim-by-claim mapping is `docs/claim_ledger.md`. Where an exact value (sample size, effect size, certainty rating, or deep-link URL) is not verified, the table records it as "verify before public release" rather than stating it as fact.

## Search log (S02, 2026-08-03)

This is a **targeted, non-systematic** student review. It is documented honestly and is **not** a systematic review or meta-analysis.

- Method: curate and map authoritative sources already named in the project design (`README.md` references) and the minimum-baseline list below; extract the claim each source may support and its limitations.
- Source categories consulted: government health-agency overview (S1); systematic reviews (S2, S3); ethics and policy frameworks (S4, S5); autistic self-advocacy perspective (S6); vendor technical documentation for the AI and UI components (S7, S8).
- What was **not** done: no reproducible database query strings were executed, no result counts were tallied, and no quantitative findings were extracted beyond what the cited reviews themselves report. Any specific numbers or deep-link URLs must be verified against each source before public release.
- Selection criteria: prefer systematic reviews and authoritative overviews for substantive health claims; use self-advocacy and policy/ethics sources for language and posture; use vendor documentation only for technical claims about the software stack.
- Limitations: a student-curated mapping can miss relevant evidence and cannot support clinical claims. Findings inform the project's language, scope, and disclosure; they do not validate any synthetic output.

## Minimum baseline references

- NIMH: Autism Spectrum Disorder overview and sensory differences.
- Cochrane: *Music therapy for autistic people* (2022).
- Cochrane: auditory integration therapy/sound therapies review, to distinguish different interventions.
- HHS OHRP: Belmont Report.
- UNESCO: Recommendation on the Ethics of Artificial Intelligence.
- Autistic Self Advocacy Network: identity-first language and intervention ethics perspectives.
