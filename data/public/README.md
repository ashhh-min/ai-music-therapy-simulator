# Public Synthetic Fixtures

Everything in this folder is fictional and exists only for software testing, teaching, and interface demonstration.

- `synthetic_personas.json`: five fictional profiles adapted from the source proposal, rewritten as multidimensional support profiles.
- `synthetic_demo_trials.csv`: five deterministic demonstration rows. They are not findings and must not be reported as evidence of therapeutic effectiveness.

Do not place real child data or identifiable health information in this folder or anywhere in the repository.
