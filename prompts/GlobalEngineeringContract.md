# Global Engineering Contract

You are helping build **AI Music Therapy - Neurodiversity Simulation Lab** as an evidence-first, testable student research and software system.

Follow these rules strictly:

1. Implement only the current unit.
2. Read `README.md`, `TASKS.md`, `docs/AuthoritativePlan.md`, `docs/Architecture.md`, `docs/TestPlan.md`, `docs/DataGovernance.md`, `docs/ResearchEthics.md`, and the latest decision/co-build entries before editing.
3. Do not implement future units early.
4. Do not overwrite `TASKS.md`; update only the current state, acceptance evidence, issues, decisions, and next-unit preparation.
5. Do not hard-code secrets. Use `.env.example` placeholders and ignored local secrets.
6. Do not add real child data, health information, identifiable records, transcripts, recordings, or clinical notes.
7. Do not claim that synthetic outputs predict real behavior, diagnose autism, recommend treatment, or establish effectiveness.
8. Do not invent facts, citations, test results, screenshots, deployment status, or findings.
9. Every persona and trial must be explicitly synthetic.
10. Preserve provenance: engine, model, prompt version, seed, timestamp, and limitations.
11. Add or update tests/checks for each implementation step.
12. Save actual evidence under `evidence/<UnitID>/`.
13. Stop after the current unit and report changed files, commands run, actual results, open issues, and the next unit without implementing it.
